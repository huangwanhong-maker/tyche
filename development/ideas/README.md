# ideas: Seeds

## 1. Purpose

This is the cheapest place to write a thought down. An idea here may be wrong, and that is acceptable.

## 2. Convention

- **One file per idea.** Name it `YYYY-MM-DD-slug.md`, and give it the front matter `status: seed`.
- **Promoting an idea.** Move its substance into a module or a decision record. Set the idea's status to `promoted`, and add a link to where the substance went.
- **Abandoning an idea.** Do not delete it. Set its status to `abandoned`, and add one sentence saying why.
