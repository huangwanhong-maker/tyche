# release-notes: What Each Commit Brought

## 1. Purpose

A running record, for readers, of what each commit made possible or better. It is written at each commit, and not between commits.

## 2. Convention

- One file per day, `YYYY-MM-DD.md`; within it, one short section per commit (or per group of commits made together), newest first, headed by what it brought.
- Each section is a clear, concise summary in plain prose: what is new, what one can now do, what works better. It is not a list of changed files or functions; the git log keeps that. The decision or note behind it is linked.
